# TaskFlow AI

AI-powered project and task management platform — built as part of Innovation Hacks Full Stack Development Internship.

## Task 1: Developer Productivity Dashboard

This is the frontend built using React.js and Tailwind CSS.

### Features
- Responsive dashboard with stat cards
- Project cards with progress tracking
- Task list with status badges (todo / in-progress / done)
- Search and filter functionality
- Loading and empty states
- Clean, reusable component architecture

### Tech Stack
- React.js
- Tailwind CSS
- Lucide React (icons)
